What this study is

BurnettBench Study 2 measures what happens when an AI is given an llms.txt V2 guide that does not fully cover all possible questions about an institution. We tested five institutions, five AI models, and 263 ground-truth facts across six experimental conditions (A, V2, FIX1–3, OPT2, OPT3) plus a classifier experiment series (OPT4, OPT4v2, OPT5, OPT4_263).

The main finding: giving the AI an incomplete guide reduces accuracy on facts the guide does not cover, and the failure mode is confident wrong answers — not hedging.

How to replicate

You need Python 3.10+, an OpenRouter API key (set as OPENROUTER_API_KEY), and the packages below. The classifier experiments (OPT4_263) require a GPU — they were run on an NVIDIA GB10 (DGX Spark). 
pip install openai rank_bm25 sentence-transformers scikit-learn transformers torch requests beautifulsoup4
1
Scrape facts and build probes Run burnettbench_scrape_and_generate.py for each institution, then burnettbench_expand_groundtruth.py, then burnettbench_merge_groundtruth.py. This regenerates the *_factprobes_full.jsonl files. Skip this step if you want to use the existing probe files.
2
Run the main benchmark python burnettbench_eval_factprobe_full.py — runs conditions A (no guide) and V2 (full guide injected) across all five institutions and five models. Outputs *_factprobe_verdicts_full.jsonl.
3
Run intervention conditions Run in any order: burnettbench_eval_fix.py (FIX1–3), burnettbench_eval_gating.py (OPT2), burnettbench_eval_gating_tune.py (threshold sweep), burnettbench_eval_ksweep.py (top-k sweep).
4
Run classifier experiments python burnettbench_retrain_opt4.py (OPT4), python burnettbench_opt5.py (OPT5), python burnettbench_opt4_263.py (OPT4_263 — GPU recommended).
5
Run failure mode analysis python burnettbench_failure_analysis.py — prints the full failure mode breakdown: B vs C rates, injection paradox transition matrix, category coverage gaps.
6
Run significance tests python burnettbench_eval_significance_outv2.py and python burnettbench_eval_significance_gating.py — outputs p-values for the main findings.
